第八週教師指南｜慢慢學會 SQL Server

本週縮為 60–90 分鐘。課前確認 SQL Server Express／SSMS；課中只完成資料庫操作，EF Core 與 Migration 不列入必做。

課前 Windows／SSMS 實機試跑清單

下載課前試跑清單 PDF（A4／5 頁）

PDF 保留 12 個步驟勾選欄、每步備註空間與獨立試跑紀錄頁，適合黑白列印後手寫。

這份清單供教師在實際上課的 Windows 環境驗證，勾選只代表你已實際確認該步；網站不會自動執行 SQL 或判定通過。建議課前預留時間，遇到不符合預期的結果先處理，再進下一步。

主流程順序：建庫 → 核對資料庫 → 建表 → 記錄筆數 → INSERT 一次 → SELECT → 重開後再查。網頁貼上 SQL 與下載檔擇一執行；新增指令不重複跑。使用課堂假資料。既有物件不刪除重建，試跑後記下保留的資料筆數。

可直接勾選或列印本頁；勾選狀態不會保存，重新整理會重設。

操作：使用上課會用的 Windows 電腦與 Windows 帳號。下載並完整解壓縮 學生包，確認 SSMS 已安裝；記下 Windows、SSMS、SQL Server 版本與測試日期。

應看到：看得到 start-here.html、images 資料夾與六份 .sql；以 SSMS 的 File → Open → File 開啟檔案。

不符合時：只有 SSMS 但未安裝資料庫引擎：先回第二週安裝指引補齊。不要在 ZIP 預覽內直接操作。

操作：Windows 按 Win+R，輸入 services.msc。找到 SQL Server (SQLEXPRESS)，確認正在執行；若課堂使用其他執行個體，依實際名稱確認。

應看到：資料庫引擎服務為 Running／執行中。SQL Server Agent 不必為這堂課啟動。

不符合時：找不到服務：確認有安裝 SQL Server Express，而不只是 SSMS／LocalDB。無法啟動：記下服務錯誤，請機房管理員協助；不要繼續測試連線。

操作：啟動 SSMS；Server Name 填 localhost\SQLEXPRESS，Authentication 選 Windows Authentication，Database Name 保留 <default>，按 Connect。傳統視窗的 Server type 選 Database Engine。

應看到：Object Explorer 出現正確伺服器，能展開 Databases。記下實際連線名稱；.\SQLEXPRESS 是同一本機具名執行個體的寫法。

不符合時：連線逾時／找不到伺服器：先核對名稱與上一步服務。憑證不受信任：僅在已核對目的地的本機教學連線，可用 Mandatory 加 Trust Server Certificate；Strict 不適用這個略過驗證方式。登入失敗：確認目前 Windows 帳號有登入權限，請管理員處理，不改用不明帳密。

操作：右鍵自己的伺服器 → New Query。若 CampusActivityLab08 尚不存在，開啟 00-create-database.sql，取消反白，按 F5 一次。右鍵 Databases → Refresh。

應看到：Messages 無建立錯誤，左側列出 CampusActivityLab08。

不符合時：已存在：記錄「沿用既有資料庫」，跳過 CREATE DATABASE，不刪除重建。建立權限不足：請管理員在指定的課堂執行個體建立練習區並配置必要權限；記錄為尚未完成。

操作：開新查詢分頁，選取 CampusActivityLab08，執行下方確認指令。每次換分頁都再看一次目的地。

USE CampusActivityLab08;
GO
SELECT DB_NAME() AS CurrentDatabase;

應看到：Results 的 CurrentDatabase 是 CampusActivityLab08。

不符合時：結果為 master：先執行完整 USE／GO 與 SELECT。找不到資料庫：回上一步確認名稱與伺服器。未反白時 F5 執行整頁；有反白時只執行選取部分，不能漏掉 USE。

操作：若表尚不存在，執行 01-create-table.sql 一次。左側 CampusActivityLab08 → Tables，右鍵 Refresh；展開 dbo.Registrations → Columns。再右鍵資料表 → Design，選取 Id 資料行，查看下方 Column Properties → Identity Specification。查看後關閉，不儲存設計變更。

應看到：看到 Id：int、主鍵、NOT NULL、Identity=Yes（Seed=1、Increment=1）；DisplayName 與 Session：nvarchar(20)、NOT NULL。第一次建立時為空表。

不符合時：物件已存在：不重建，直接核對欄位。欄位不符：先確認是否連錯資料庫；請教師／管理員釐清舊表來源。01-setup.sql 不會修復舊表結構，不要用刪表解錯。

操作：執行 03-select.sql，確認能查到三欄。另在同一資料庫執行：

SELECT COUNT(*) AS BeforeCount
FROM dbo.Registrations;
記下 BeforeCount，保留查詢分頁。

應看到：第一次建表為 0 列；沿用舊表則是現有列數。空結果仍有 Id、DisplayName、Session 欄名。

不符合時：Invalid object name：先查 DB_NAME()，再確認 dbo.Registrations 拼字與建表訊息。僅紅色波浪線但查詢成功：可能是 IntelliSense 快取未更新，先以實際 Messages／Results 為準。

操作：只執行 02-insert.sql 一次。查看 Messages，然後切回查詢分頁重跑 03-select.sql 與 COUNT(*)，記下本次新增的 Id。不要再執行 INSERT。

應看到：Messages 顯示 1 row affected／影響 1 列；總筆數比 BeforeCount 多 1；查到小安／上午場。Id 由資料庫產生，不要求一定為 1。

不符合時：多了兩筆：檢查是否重跑 INSERT 或網頁與下載檔各跑一次。中文亂碼：核對 nvarchar 與 N 前綴、SQL 檔的 UTF-8 顯示。NULL／主鍵錯誤：核對表結構及執行內容，不自行補填 Id。結果看不出新筆數時，先查詢，不盲目再新增。

操作：記下 Id／姓名／場次，關閉查詢分頁。右鍵伺服器 → New Query，執行指南第 9 步的 USE／GO 與 SELECT，或重新開啟 03-select.sql。

應看到：仍查得到同一個 Id、小安、上午場，總筆數未變。儲存 .sql 只保存指令文字，不影響已寫入資料庫的資料。

不符合時：查不到：先確認同一台伺服器、同一資料庫與先前 INSERT 是否成功。Results 未顯示表格：Ctrl+D 後重跑 SELECT。不可為了找資料再次執行 INSERT。

操作：在上述資料確認後，執行 01-setup.sql，再執行一次；核對每次的 Results。這是備援檢查，不是重新新增小安。

應看到：CurrentDatabase 仍正確；既有表、資料列與 Id 保留，筆數未增加。若本次原本已有物件，這只驗證「已存在就跳過」的路徑。

不符合時：權限或欄位錯誤：依 Messages 第一個錯誤處理，停止重跑。欲驗證全新建庫／建表路徑，另用尚未建立本課資料庫的教師測試環境；不要清空學生資料。

操作：開啟 04-optional-filter.sql。尚未新增選做資料時，選 A 段（含 USE／GO）執行一次；之後只選 B 段（含 USE／GO）執行。改上午場為下午場，再試 ASC／DESC 與不存在的場次。

應看到：A 段新增兩列：小晴／下午場、小宇／上午場。B 段只列上午場且 Id 由大到小；下午場不含上午場；不存在的場次為 0 列。重跑 B 段筆數不增加。

不符合時：每次查詢都多兩筆：誤跑整份或選到 A 段，改成只選 B 段。若已有練習資料，不要求固定結果列數；改用條件、排序與新增前後差異驗收。60 分鐘課程可標記本步「不適用」。

操作：以教室投影設備開啟簡報第 6–13 頁、PDF與九步指南，核對圖片與 SQL；解壓後暫時斷網開啟 start-here.html，測試圖片及手動複製 SQL。

應看到：圖片文字可讀；資料庫／資料表名稱一致。離線指南九步、圖片與本機 SQL 檔可用。將驗收證據記在下方；課前備妥無法連線者的同桌輪流方案。

不符合時：舊圖或舊 SQL：重新下載最新 PDF／ZIP 並解壓，網頁強制重新整理。圖片不見：保留 images 資料夾及解壓後結構。離線複製按鈕受限時手動選取 SQL；外部參考連結需網路。

課前準備摘要

在自己的 Windows／SQL Server 環境先按指南順序檢查六個 SQL 檔（含一份建庫／建表備援）。setup 可重跑且不清資料；insert 每跑一次會再新增。本次採查詢編輯器建庫／建表；已建好的物件直接跳過，不刪除重建。不要把手動建的 Lab08 資料表交給 EF Migration 管理。

學生卡住時

先確認服務與執行個體，再確認 DB_NAME()，最後看 Messages 第一個錯誤。已存在的表不刪除；重複小安用不同 Id 說明重複新增。環境尚未完成可同桌輪流實作，另記錄需補裝的學生。
