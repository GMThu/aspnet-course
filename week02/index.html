遇到憑證錯誤，先確認連的是誰。

僅適用：自己的 localhost\SQLEXPRESS，且錯誤明確指出憑證鏈不受信任。

本機課堂處理方式

  1. 核對 Server Name 是自己的 localhost\SQLEXPRESS。
  2. 保留 Encrypt：Mandatory。
  3. 勾選 Trust Server Certificate／信任伺服器憑證，再 Connect。

這個選項代表什麼？

會略過伺服器憑證驗證，不是修好了伺服器的憑證。

正式或遠端環境應使用可信任憑證；不要一律照勾。

這和 ASP.NET 網站的 HTTPS 開發憑證，是不同的連線與設定。

先留意 若錯誤是找不到伺服器或登入失敗，勾這個不會解決；請到後面的排錯頁。
