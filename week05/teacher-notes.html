常見問題與處理順序

Razor 編譯失敗
  1. 確認沒有第二組 @page、@model。
  2. RegistrationInput 放在 IndexModel 類別內。
  3. 確認 DataAnnotations 與 MVC 的 using。
  4. 只先讀第一個編譯錯誤。
按送出沒有進 OnPost
  1. form 是 method="post"。
  2. submit 位於 form 內。
  3. Handler 命名為 OnPost()。
  4. 用中斷點確認，不整頁重寫。
Input 全是空值
  1. asp-for 使用 Input.DisplayName 等完整路徑。
  2. Input 有 [BindProperty]。
  3. Razor 與 C# 屬性拼字一致。
預設場次也能通過

預設 option 必須是 value=""，不要在 OnPost 比對顯示文字。

錯誤資料仍顯示成功

確認 Submitted = true 位於 ModelState.IsValid 通過之後。

學生說資料已經存好了

請他重啟專案，再問「從哪裡查回上一筆？」本週應描述為收到、驗證、回應，不是持久保存。

補強

只保留名稱、Email、場次；完成 POST、兩項驗證與成功摘要。

一般主線

四欄、三條測試、同儕回報與標準 Boss。

提早完成

老師指定一題進階 Boss；不自行接資料庫或登入。

Boss 使用方式

  1. 先確認共同三條測試已通過。
  2. 老師依狀態指定基礎救援、標準任務或進階委託。
  3. 同級內才抽題，避免難度由運氣決定。
  4. 四項都要看到：重現、修改、測試、說明。

驗收用語

  • ad-hoc green：只代表某次輸入與操作成功。
  • 本週驗收：三條測試、390px 可操作、localhost 實際執行、學生能沿五站解釋。
