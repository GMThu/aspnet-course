POINT 01 · GET VS POST

GET 是拿報名頁，
POST 是交出欄位資料。

第一次開啟首頁，瀏覽器向伺服器拿 HTML；填完按下送出，才把 form 內的資料交給後端。

GET／拿頁面

瀏覽器 ── GET / ──→ 伺服器 瀏覽器 ←── 表單 HTML ──

對應 Razor Pages 的 OnGet。

POST／交資料

瀏覽器 ── POST / ─→ 伺服器 名稱、Email、場次

對應今天要完成的 OnPost。

先記「拿」和「交」，不背 HTTP 大全10

POINT 02 · FORM BOUNDARY

form 像一個資料信封，
只有信封裡的欄位會一起送出。

<form method="post"> <label>顯示名稱</label> <input ...> <button type="submit"> 送出報名 </button> </form>

先預測

如果 input 放在 </form> 後面，按下送出時，它會一起送嗎？

</form> <input name="note"> <!-- Form 表單外 -->

先選答案，再用「信封範圍」解釋。

method="post" 描述這次送出的方式11

POINT 03 · LABEL BEFORE STYLE

label 不是裝飾，
它把「問題」和「輸入位置」連起來。

點一下「顯示名稱」，游標也會進入輸入框。

<label for="nameDemo"> 顯示名稱 </label> <input id="nameDemo">
Placeholder 只是範例，輸入後會消失；不能取代 label。
可操作與可理解，先於漂亮12

POINT 05 · PAGE MODEL

Index.cshtml 負責呈現，
Index.cshtml.cs 負責處理。

同一個 Razor Page 有兩個合作檔案：一個面對使用者，一個接住請求與資料。

Pages/ ├─ Index.cshtml │ └─ 表單、欄位、結果 │ └─ Index.cshtml.cs └─ Input、BindProperty、OnGet、OnPost
前端與後端分工，但共同完成一頁16

POINT 06 · INPUT MODEL

四個欄位，不要散成四條線；
用一個 Input 物件收在一起。

public class RegistrationInput { public string DisplayName { get; set; } = string.Empty; public string Email { get; set; } = string.Empty; public string Session { get; set; } = string.Empty; public string? Note { get; set; } }
InputDisplayName
InputEmail
InputSession
InputNote
同一個用途的輸入，組成一個模型17

POINT 07 · MODEL BINDING

[BindProperty] 讓 ASP.NET
把 POST 欄位放進 Input。

[BindProperty] public RegistrationInput Input { get; set; } = new();

Binding 做了什麼？

  1. 找出送來的欄位名稱。
  2. 比對 Input.DisplayName 等屬性。
  3. 把文字轉成屬性需要的型別。
  4. 把這次請求的值放進 Input 物件。
它不是資料庫。Binding 只把這次請求帶來的值放進 C# 物件。
收到資料 ≠ 保存資料18

POINT 08 · HANDLER

表單用 POST 送出時，
Razor Pages 會尋找 OnPost()。

public bool Submitted { get; set; } public void OnPost() { Submitted = true; }

和 OnGet 的分工

OnGet：第一次開啟頁面。

OnPost：使用者送出表單。

POINT 09 · RESPONSE

成功摘要不是另一個神祕頁面，
是 Razor 根據狀態決定要不要顯示。

@if (Model.Submitted) { <section class="alert alert-success"> 報名資料已收到 參加者：@Model.Input.DisplayName </section> }

現在能證明什麼？

後端收到這次 POST，並把 Input 的值放回 HTML 回應。

還不能證明什麼？

不能證明資料已存入 SQL Server，也不能證明重新啟動後還找得到。
