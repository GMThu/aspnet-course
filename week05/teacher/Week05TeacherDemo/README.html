WEEK 05 · 教師完整專案

Razor Pages 表單資料流

目標框架：.NET 10 LTS

Visual Studio 2026 開啟方式

  1. 解壓縮 ZIP。
  2. 選「開啟專案或方案」。
  3. 開啟 Week05TeacherDemo.csproj。
  4. 按 Ctrl + F5。
  5. 瀏覽器應開啟 localhost；port 以 Visual Studio 顯示為準。

教學檔案地圖

  • Pages/Index.cshtml：form、asp-for、錯誤與成功摘要。
  • Pages/Index.cshtml.cs：BindProperty、OnPost、Annotations、ModelState。
  • wwwroot/css/site.css：桌機與手機版面。
  • preview.html：沒有 SDK 時先看畫面；不能取代 localhost 驗證。

示範順序

  1. GET：指出 OnGet 與空白表單。
  2. 空白 POST：三個必填錯誤。
  3. Email 輸入 abc：格式錯誤。
  4. 合法假資料：成功摘要與輸入一致。
  5. 重啟網站：說明資料未寫入資料庫。
