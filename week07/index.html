MODEL · SEPARATE RESPONSIBILITIES

輸入表單與資料表，
不必是同一個 C# 類別。

RegistrationInput

接住使用者這次輸入。

  • 有 Required、EmailAddress
  • 可保留 UI 專用欄位
  • 不代表資料表已保存

Registration Entity

代表資料庫的一筆報名。

  • 有主鍵 Id
  • 保存通過驗證的值
  • 可加入 CreatedAt

快問：哪個描述正確？

Input 是入口；Entity 是保存形狀06

ENTITY · ONE ROW

一個 Registration 物件，
對應資料表的一列。

public class Registration { public int Id { get; set; } public string DisplayName { get; set; } = ""; public string Email { get; set; } = ""; public string Session { get; set; } = ""; public string? Note { get; set; } public DateTime CreatedAt { get; set; } }

先只看三件事

Id：主鍵，用來分辨每一筆。

欄位：要保存的值。

CreatedAt：由後端產生，不讓表單決定。

Entity 先保持簡單，不在本週加入關聯07

DBCONTEXT · DATABASE WINDOW

DbContext 不是資料庫，
它是程式與資料庫之間的工作窗口。

DbContext
public class CampusActivityContext : DbContext { public CampusActivityContext( DbContextOptions<CampusActivityContext> options) : base(options) { } public DbSet<Registration> Registrations => Set<Registration>(); }

DbSet 是從程式操作 Registration 資料表的入口。

Entity 定義形狀；DbContext 提供操作入口08

MIGRATION · SCHEMA PLAN

Migration 是資料表結構的變更計畫，
不是報名資料本身。

Entity目前 C# 想要的資料形狀
Migration把形狀轉成可追蹤的結構變更
Update把尚未套用的變更送到資料庫
TableSQL Server 出現 Registrations
Migration 檔要看懂並提交；資料庫是否套用仍需實際查證。
產生 Migration 與套用 Migration 是兩件事13

TOOLS · TWO COMMANDS

命令只做兩步：
產生計畫，再更新資料庫。

SAVE GATE · VALID FIRST

資料庫不該替表單驗證收爛攤子。
ModelState 失敗就立刻返回。

public async Task<IActionResult> OnPostAsync() { if (!ModelState.IsValid) { await LoadRegistrationsAsync(); return Page(); } // 只有通過驗證才建立 Entity 與保存 }
回到同一頁時仍需重新載入列表，避免畫面只剩表單、原有資料消失。
失敗路線要證明資料列數沒有增加18

MAPPING · CHOOSE WHAT TO SAVE

不要把整個輸入物件直接當資料列；
明確選擇要保存的欄位。

var registration = new Registration { DisplayName = Input.DisplayName, Email = Input.Email, Session = Input.Session, Note = Input.Note, CreatedAt = DateTime.UtcNow };

後端負責的值

Id：由資料庫產生。

CreatedAt：由後端產生。

不保存：成功訊息、確認勾選等 UI 狀態。

Mapping 也是權限與資料邊界19

EF CORE · TRACK THEN COMMIT

Add 先讓 Context 追蹤；
SaveChangesAsync 才送到資料庫。

_db.Registrations.Add(registration); await _db.SaveChangesAsync(); TempData["SavedMessage"] = "報名已保存"; return RedirectToPage();

Add：登記「這是一筆要新增的資料」。

SaveChangesAsync：真正執行 INSERT；成功後 Redirect，重新整理不會重送同一筆 POST。

POST → Save → Redirect → GET20

QUERY · READBACK

保存後再查回，
畫面才有資料庫證據。

public List<Registration> Registrations { get; set; } = []; public async Task OnGetAsync() { await LoadRegistrationsAsync(); } private async Task LoadRegistrationsAsync() { Registrations = await _db.Registrations .AsNoTracking() .OrderByDescending(x => x.Id) .Take(10) .ToListAsync(); }

本週只取最近 10 筆

避免一次載入全部資料。

列表只顯示課堂假資料。

先不教搜尋、分頁、編輯與刪除。

Query 的結果交給 Razor 顯示21
