# 第七週｜期末專題提案準備包

用任何形式提出期末專題的提案計畫。簡報、海報、草圖、故事板、角色扮演、影片、紙上或互動原型等形式皆可。

1. 開啟 start-here.html 看準備說明。
2. 用 report-outline.txt 整理使用者問題、解決構想、使用情境、核心功能、分工與進度、待確認事項。
3. 用 test-record.txt（提案檢核與回饋表）檢查內容並記錄同儕建議；此表不要求程式測試。

不要求已完成網站、程式、輸入驗證測試或資料庫串接；已有成果可以輔助說明。AI／外部素材請說明用途、來源及人工查證。
期中報告占 25%，沿用課程規定；時間、順序、期限與繳交平台依老師公告。
第八週起逐步學習資料庫技術，並依回饋修訂期末專題方向。
