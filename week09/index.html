CONNECTION

先看 Server，再看 Database。

"CampusActivity": "Server=localhost\\SQLEXPRESS;Database=CampusActivityLab09;Trusted_Connection=True;Encrypt=True;TrustServerCertificate=True"
  1. 鍵名 CampusActivity 要與 GetConnectionString 一致。

這是 ConnectionStrings 內的一行，不是完整 JSON；請修改提供的完整 appsettings.json。本機教學才信任已核對的伺服器憑證。

SAVE

Add 安排新增，SaveChanges 才寫入。

var registration = new Registration
{
    DisplayName = Input.DisplayName,
    Email = Input.Email,
    Session = Input.Session,
    Note = Input.Note
};
_db.Registrations.Add(registration);
await _db.SaveChangesAsync();

實際程式在 OnPostAsync；await 等待資料庫工作完成，成功後才顯示「已保存」。

POST → REDIRECT → GET

保存後改成 GET，再看結果。

SavedMessage = $"已保存報名，編號 {registration.Id}";
return RedirectToPage();
  1. 合法假資料只送出一次；SSMS 總筆數 +1。
  2. 成功後按重新整理，不會再次送出同一個 POST。
  3. 這不是防重送鎖；再次按送出仍會新增另一筆。

QUERY · 85–105 MIN

GET 查回最近 10 筆。

Registrations = await _db.Registrations
    .AsNoTracking()
    .OrderByDescending(item => item.Id)
    .Take(10)
    .ToListAsync();
  1. 停止網站，套用 03-Query 的兩個 Pages 檔，再 dotnet clean。
  2. OnGetAsync 呼叫 LoadRegistrationsAsync。
  3. AsNoTracking 適合唯讀清單；ToListAsync 才執行查詢。

OrderByDescending：大的 Id 在前。Take(10)：限制顯示，不會刪除其餘資料。
