# 東海 ASP.NET 課程

從校園需求到可驗證的網站應用。以 ASP.NET 為主軸，練習需求描述、資料與流程設計、AI 協作及測試驗證。

## 課程安排

- 18 週：14 週教學、期中與期末專題報告各 1 週、最後 2 週自主學習。
- 第一週：課程地圖、網站觀念、AI 協作、問題提案。
- 第二週：安裝環境，建立、啟動及修改第一個 ASP.NET 網站。
- 第 1–4 週：熟悉工具，動手修改；依學習狀況補充基礎，不要求固定在第 3–4 週完成表單。
- 第 5–9 週：完成一個小流程，逐步認識資料處理與保存；第 9 週期中報告。
- 第 10–16 週：補齊核心功能與資料保存，測試、試用與改善；第 16 週期末報告。
- 第 17–18 週：提供基礎與進階資源，依個人需要自行選學，不新增核心必修功能。
- 後續每週講義依授課進度新增，不預先建立無內容連結。

### 彈性教學原則

- 報告日期固定，功能範圍與教學深度依學習狀況調整；先把核心做懂、做穩，再挑戰進階功能。
- 每次實作安排共同必做與選做挑戰。理解較慢時縮小功能、補強觀念；進度較快時深入同一流程，不以功能數量競賽。
- 第 4、8、12、15 週保留整合與練習彈性，不預先塞滿新內容；可用於補強、除錯、同儕試用或進階挑戰。
- 以小幅修改、說明資料流與預測操作結果確認理解，再決定是否進入下一主題。
- 期中以問題說明、可操作的小流程與下一步改善為重點，不要求整套系統完成；若使用暫存資料，須說明尚未持久保存與重啟後會消失的限制。具體要求提前公告。
- 期末補齊小作品必要的資料保存與查詢，實際測試並依試用回饋改善。登入、權限與自動化測試依作品需要及學習狀況深化；涉及個資或管理操作時，不得省略必要保護後公開使用，基礎示範可使用假資料與本機環境。
- 自主學習週不承接前面未教完的核心必修內容。評分比例不變：出席 5%、隨堂作業與考試 35%、期中報告 25%、期末報告 35%。

## 第一週操作

- 左右方向鍵換頁；Home 回到第一頁。
- 可用目錄、全螢幕、連續閱讀模式、列印／PDF。
- 第 7 頁：報名、重複報名與取消模型。
- 第 10 頁：逐步查看請求流程，每一步附對應箭頭流程圖，亮框標示重點。可用「下一步／從頭看」或直接點選五個步驟；手機改為直向流程，PDF 顯示完整五步總覽。
- 第 17 頁：複製 AI 提問。
- 第 18 頁：故意有錯的報名模型。
- 第 25 頁：問題提案表，可下載文字檔。
- 第 27 頁：課堂檢核，點擊展開答案。

網頁簡報是單檔 HTML，可下載後直接開啟。只有延伸閱讀連結需要網路。

## 發布與更新

GitHub Pages 使用 `main` 分支的根目錄 `/`。提交並推送更新後，由 GitHub 自動建置發布。

新增週次時，建立 `week02/index.html` 等目錄，再更新首頁的講義入口。保留既有週次網址，方便學生持續使用。

推送不等於發布完成；更新後需確認 Pages 建置成功，並開啟公開網址檢查實際內容與互動。

- 網站為公開靜態教材，沒有學生帳號或後端資料收集。
- 提案表草稿僅保存於本機瀏覽器；共用電腦請清除草稿。
- 報名示範為 JavaScript 教學模型，不是實際 ASP.NET、登入或資料庫。
