# 第四週最終 Boss 抽題卡（教師用）

學生完成五關後，任選或隨機指定一題。學生須當場找到位置、完成修改、重新整理，並說明改了哪個 class 或 CSS 屬性。

1. 把按鈕從 `btn-primary` 改成 `btn-success`，說明畫面差異。
2. 暫時拿掉 `img-fluid`，縮窄瀏覽器觀察，再把圖片修好。
3. 把卡片的 `mb-4` 改成 `mb-1`，指出哪一段距離改變。
4. 在 `site.css` 將 `.activity-hero` 的 `border-radius` 改成 `0`，再恢復原值。
5. 新增一張「活動提醒」卡，沿用既有 `card` 與 `card-body`。
6. 將網站改為淺色背景，並調整文字顏色維持清楚。
7. 用鍵盤 `Tab` 找到活動按鈕，再用 `Enter` 開啟，不使用滑鼠。
8. 指出一條 CSS 的選擇器、屬性和值，並現場修改其中的值。
9. 將按鈕改成 `btn-outline-primary`，說明哪個 class 沒有改。
10. 在卡片新增一段自己的活動提醒，並套用 `text-muted` 後比較差異。
11. 把 `p-4` 改成 `p-1`，說明是卡片內部還是外部空間改變。
12. 把圖片的具體 `alt` 暫時改成「圖片」，說明為什麼較差，再恢復具體描述。

## 驗收重點

- 不比速度，重點是能找到位置、做最小修改。
- 必須在實際 localhost 儲存、重新整理並操作，不只看原始碼。
- 能說明 Bootstrap class 與自己的 CSS 各自負責什麼。
- 只會貼上整段答案、無法指出修改位置者，尚未通過。
