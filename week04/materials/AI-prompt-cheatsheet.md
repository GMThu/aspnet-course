# 第四週｜AI 程式協作提示詞小抄

AI 是結對程式設計夥伴，不是答案印表機。你的工作是：說清楚、看懂修改、實際執行、驗證結果。

## 六要素

1. **背景**：使用什麼技術？目前在哪個檔案？
2. **目標**：這次只想改善哪一件事？
3. **現有程式碼**：只貼最小相關 HTML／CSS 與錯誤訊息。
4. **限制**：哪些檔案、語法、套件不能動？
5. **輸出格式**：要先解釋、再提供最小替換片段。
6. **驗收條件**：怎樣才算真的完成？

## 可直接改寫的完整提示詞

```text
你是前端助教。我正在修改已載入 Bootstrap 的 ASP.NET Razor Page。

目標：只優化活動卡的【圖片／間距／按鈕／配色】。

現有程式碼：
【貼上最小相關 HTML 與 CSS】

限制：
- 保留 Index.cshtml 頂端的 @page、@model 與 @{ ... }
- 不修改 Index.cshtml.cs
- 不加入陌生 CDN 或新套件
- 不修改 bootstrap.min.css
- 自訂樣式只寫在 site.css
- 不要重寫整頁

輸出：
1. 先用初學者聽得懂的方式列出修改原因。
2. 再給最小可替換的程式片段。
3. 說明每個新增或更換的 class／CSS 屬性用途。

驗收條件：
- 390px 寬度沒有橫向捲動
- 圖片不超出卡片
- 標題與內文清楚可讀
- 活動連結仍能點擊
- 原本活動文字全部保留
```

## 配色任務

```text
請根據「東海夜間攝影活動」提出 3 組網站配色。
每組列出背景色、文字色、按鈕色的 hex 值，並簡短說明氣氛。
限制：不要改 HTML；深色背景上的文字必須清楚。
我會自己選擇並寫入 site.css，請不要替我重寫整頁。
```

## 除錯追問

不要只說「還是不行」。描述實際操作與現象：

```text
我已套用上一個建議。現在 localhost 在桌面寬度正常，
但瀏覽器縮到 390px 時仍出現橫向捲動；圖片已正常。
請保留目前 HTML，只找出最可能造成 overflow 的 CSS，
解釋原因，並提供最小修改。不要重寫整頁。
```

## 採用前五步

1. **讀**：逐行看懂，確認沒有碰到禁區。
2. **比**：比較修改前後，只保留需要的差異。
3. **跑**：儲存後啟動 localhost，不只看 AI 聊天視窗。
4. **測**：點連結、縮到 390px、看文字、圖片與間距。
5. **追問**：若失敗，回報實際現象並要求只修失敗處。

完成後要能回答：

- AI 建議了什麼？
- 我採用或拒絕了哪一項？為什麼？
- 我修改了哪個 class 或 CSS 屬性？
- 我如何證明修改有效？

## 絕對不要貼給 AI

- 帳號、密碼、API key、Token
- 資料庫連線字串
- 真實姓名、電話、Email 等個資
- 整個專案或不相關的大量檔案
- `bin/`、`obj/` 或正式環境設定
