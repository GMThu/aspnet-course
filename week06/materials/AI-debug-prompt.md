# 第五週｜AI 表單除錯提示詞

請只貼最小相關程式碼，不要貼整個專案、帳密、連線字串、API key 或真實個資。

```text
你是 ASP.NET Razor Pages 助教。

背景：
我的首頁有一個 method="post" 的報名表，使用 Input 模型、[BindProperty] 和 OnPost。

操作與輸入：
我輸入＿＿＿＿，然後按下＿＿＿＿。

預期結果：
我預期看到＿＿＿＿。

實際結果：
實際看到＿＿＿＿；錯誤訊息為＿＿＿＿。

最小相關程式碼：
（只貼相關屬性、OnPost 與對應 Razor 欄位）

限制：
- 不要重寫整頁。
- 不要新增套件、資料庫或 JavaScript 框架。
- 保留 @page、@model 與既有 Bootstrap。
- 先解釋可能原因，再給最小修改。

輸出格式：
1. 最可能原因
2. 建議檢查順序
3. 最小修改差異
4. 空白、錯誤格式、正確資料三組測試
```

## 收到回覆後

1. **讀**：逐行理解，確認沒有碰到禁區。
2. **比**：只保留與問題相關的差異。
3. **跑**：在自己的 localhost 執行。
4. **測**：至少走空白、錯誤格式、正確資料三條路。
5. **追問**：失敗時描述實際現象，不只說「還是不行」。

AI 回覆不是完成證據；實際執行與測試結果才是。
