先讓學生建立瀏覽器、後端、資料庫與需求描述的共同語言，再用問題提案收束。

老師提示與解答位置
  • 第 18 頁是故意有錯的報名模型，可用來引導學生找問題。
  • 第 25 頁是問題提案表；第 27 頁可展開課堂檢核答案。
  • 提案草稿只存在目前瀏覽器，不會上傳；共用電腦提醒學生清除。
WEEK 02 · 安裝實作

Windows 開發環境安裝 尚無獨立教師小抄

本週以每位學生實際完成安裝與驗證為主，不把「看到安裝完成」當成網站與資料庫都可用。

投影安裝教材PDF 講義
老師巡視重點
  • 確認 Visual Studio、.NET、SQL Server 與 SSMS 都是課程指定版本。
  • 至少驗證第一個網站能啟動，以及資料庫工具能連線。
  • 遇到卡關時先記錄學生停在哪一步，不讓全班同時重裝所有工具。

任務闖關版適合課堂操作；完整教材原版保留詳細解說與延伸內容。上課前先決定本班使用哪一版。

老師提示與驗收界線
  • 任務版進度只保存在學生目前瀏覽器的 localStorage。
  • HTML 自動檢查站不會修改學生專案；最終結果仍需在學生的 localhost 實際驗收。

WEEK 04 · CSS × BOOTSTRAP × AI

網站改造大作戰 有教師小抄

先看預期成品，再走短講解、學生實作、快速驗收；Demo 只定義完成條件，不要求所有學生做成同一配色。

投影互動簡報教師小抄／重要提示預期成品 Demo學生任務包
本週上課前必看
  • 第 2 頁先展示桌機版與 390px 手機版 Demo，提醒學生配色可以不同。
  • 三段實作在第 8、13、18 頁，時間分別為 15、20、20 分鐘。
  • 巡視時看學生是否從起始檔修改，而不是直接複製 Demo。
  • 驗收需看實際畫面、可點按鈕與 390px 不橫向捲動；只看程式碼不算完成。
